## How to Add Screenshots

1. Take screenshots of your site at each breakpoint
2. Name them as shown above
3. Place them in this directory
4. Update the main README.md to reference them

## Breakpoint Testing

Use browser developer tools to test at:
- **Desktop**: 1440px width
- **Tablet**: 768px width  
- **Mobile**: 480px width

Or use actual devices:
- **Desktop**: Any desktop computer
- **Tablet**: iPad Mini (768x1024)
- **Mobile**: iPhone/Android (typically 375-412px width)
